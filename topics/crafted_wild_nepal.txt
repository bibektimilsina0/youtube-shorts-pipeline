# Rotating topic list for --niche crafted_wild_nepal
#
# One topic per line. Blank lines and #-comments are ignored.
# scripts/next_topic.py walks this list in order and records the position in
# topics/.state/<niche>.pos, so the daily cron never repeats until it wraps.
#
# Trending-news discovery is a poor fit for this niche: the content is
# "here is a sculpture of an animal", which has nothing to do with today's
# headlines. A curated list gives even coverage of Nepal's wildlife instead.
#
# To add topics, just append lines — there is no cap. Reordering is safe;
# the position file only stores an index, so a big reshuffle may repeat or
# skip one topic in the current pass and then settle.
#
# 90 entries = one full pass per quarter at one video per day.
